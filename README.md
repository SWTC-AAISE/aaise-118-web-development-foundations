# 10-152-118 Web Development Foundations

Student-facing materials for HTML, CSS, and JavaScript foundations.

## Student workflow

Clone or fork assigned starter work to your personal GitHub account, develop locally in VS Code, commit regularly, and submit the required repository link. Paired work uses one shared student repository with both contributors.

## Course map

01 HTML multi-page site; 02 CSS appearance; 03 layout and responsiveness; 04 JavaScript logic; 05 DOM interaction; 06 debugging; 07 structured JavaScript; 08 asynchronous behavior; 09 modular thinking; 10 data APIs; 11 state and local storage; 12 performance; 13 security and reliability; 14 UX refinement; 15 forms and input.

`[PageForge](https://github.com/cashmy-swtc/PageForge)` is the instructor demonstration project. It is a reference model, not a required project to copy.

See [weeks](weeks/README.md) for the release hierarchy.
